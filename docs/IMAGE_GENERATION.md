# Taleoria 本機插畫整合

此功能接上 Draw Things HTTP API，提供場景、玩家與已遇見 NPC 的肖像、目前持有的物品圖片。單張背景工作支援快取、重新生成、下載及共用美術風格，圖片不改動世界資料。

## 安裝

插畫功能已內建於此完整專案，不需另外安裝 ZIP 更新。第一次使用依照根目錄 [INSTALL.md](../INSTALL.md) 安裝 Draw Things、匯入 DreamShaper XL Lightning 並啟用 HTTP API，再開啟 Taleoria → 遊戲設定 → 插畫。

## Draw Things

- 載入 `DreamShaperXL_Lightning`。
- Advanced → API Server：HTTP、Server Online 開啟、Port 7860、IP `127.0.0.1 (localhost only)`，Bridge Mode 關閉。
- Taleoria 預設網址：`http://127.0.0.1:7860`。按「儲存並測試連線」。
- 生圖請求使用 4 步、CFG 2、DPM++ SDE Karras、Batch 1；場景 1024×768、肖像 768×1024，不啟用放大。
- 模型沿用 Draw Things 中選定的模型；此 HTTP 整合不會替你切換模型。

## 使用

不另設「冒險插畫」面板。地點卡右上角有生成圖示及「檢視圖片」，玩家側欄與完整角色卡、人物卡及背包物品卡也各有相同圖示。物品詳情內可以生成、點圖開啟大圖；人物頭像亦可點開。尚未生成時檢視圖示停用，生成圖示保持可用。

完成後圖片填入既有背景、肖像或物品位置。每段故事下方另有「描繪這一刻」，手動生成該回合的場景插畫，顯示在對應段落下；冒險記事中的舊回合也能生成與檢視。所有生圖按鈕都有滑鼠提示。大圖在對話框中檢視，提供下載、重新生成與可選的英文構圖描述。生成期間圖示顯示動畫，完成後原位更新；失敗圖示變色並提供原因，已存在的圖片保留。大圖檢視本身不會再生成圖片。

場景沿用目前所在地的可見描述；人物只用已遇見的人物資料；物品只用目前持有物品的名稱、描述與題材。數量改變不會作廢同一外觀的圖片，外觀改變或換戰役則不沿用不符資料的圖片。物品圖採 768×768 靜物構圖，不新增能力或物品。

英文描述留白時，以獨立的 KoboldCpp JSON 請求翻譯玩家可見的外觀與場景資料；不傳入 GM 私密資料或人物內心。「描繪這一刻」只讀取所選回合保存的公開敘事、行動與當時人物外觀；之後的故事不會改寫該畫面。玩家行動代表嘗試，畫面以敘事記錄的實際結果為準。也可以輸入自訂英文描述，完全略過這次文字模型請求。

圖片只是視覺詮釋，可能仍有模型自行補出的細節；不會寫回世界設定、人物外觀、背包或劇情日誌。圖片資料另存在遊戲資料目錄下的 `illustrations/`，依戰役、來源進度與視覺資料辨識。重啟、同機讀檔時可重用，切換戰役或回溯不會顯示未來進度圖片。

**目前 `.rpgsave` 不內嵌圖片。** 搬到另一台電腦時，請保留完整 `data/`（包含各戰役的 illustrations 圖片與資料庫）；也可逐張按「下載圖片」。此版本沒有角色參考圖或 LoRA 訓練，不能保證重新生成後同一 NPC 的臉完全一致。

## 16GB 記憶體與排程

文字／人物整理和圖片生成使用同一工作鎖，避免同時推理。生圖過程仍可讀取故事、圖片進度與切換頁面；新的文字工作會等待本次生圖結束。這不會自動卸載或重啟 KoboldCpp，也不保證兩個模型的常駐記憶體能完全容納。若遇明顯換頁或記憶體不足，可暫停其他大程式，或先用自訂英文描述測試；必要時再單獨停止／載入模型。

## 驗證與限制

提供 `tests/test_illustrations.py` 和 `tests/test_illustrations_ui.cjs`，涵蓋權限、工作識別、快取、重啟、跨戰役隔離、人物隱私、錯誤恢復、工作互斥、HTTP 請求及前端狀態切換。

已在正式網頁驗證既有 Draw Things 場景圖可原位顯示並開啟大圖，以及玩家、人物、背包、物品詳情的圖示和 390px 手機排版。物品生成另由隔離的服務／HTTP 測試驗證，沒有為介面測試推進正式故事。重新生成仍可能改變同一人物的長相，圖片不是世界真相的證據。

## 備份

停止 Taleoria 後複製完整 data，或使用 `python3 scripts/package_release.py --private` 製作包含進度與圖片的私人搬機包。升級程式前先保留備份。
