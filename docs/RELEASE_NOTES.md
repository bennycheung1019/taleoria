# 0.9.0-local — 可攜式專案整理

整理日期：2026-10-30。

- 以 Taleoria 命名專案與 Mac／Windows 啟動檔，提供 Linux 啟動指令。
- 保留現有對話、規則、背景人物整理與卡片內生圖功能。
- 加入專案相對的啟動設定，可調整 KoboldCpp 網址、遊戲 port 與起始資料庫。
- 存檔索引寫入磁碟時改用相對路徑，支援資料夾改名與跨使用者搬機。
- 加入舊專案資料複製、SQLite 備份與索引轉換工具；不覆蓋已有的目的進度。
- 分開打包乾淨安裝版及含資料、圖片的私人備份，模型由使用者另行安裝。
- 補齊簡易安裝指南、模型與應用官方下載連結、搬機及 GitHub／Vercel 架構說明。

## 本輪驗證

- 231 個不需 socket 的 Python 回歸測試通過，其中 8 個新測試涵蓋真正搬動資料夾、舊絕對路徑遷移、保護目的資料、設定、乾淨包與私人包。
- 前端卡片／圖片檢視／非同步狀態回歸通過；app.js、illustrations.js 及 Mac／Linux 啟動腳本語法通過。
- Markdown 本地連結檢查通過。
- 本機遷移另外逐一比對 7 個遊戲資料庫的目前狀態、完整 journal 與雜湊鏈；兩張 PNG 位元組相同。
- 工作環境禁止啟動 localhost socket，36 個 HTTP 整合測試因此明確略過；沒有宣稱全套或新程序的端到端啟動已驗證。可在自己的電腦執行 `python3 scripts/run_checks.py` 補做。

跨分頁即時同步、雲端存檔、Vercel 前端／本機 companion、Windows 生圖的完整實機驗證、角色參考圖及自動卸載模型。
