# 人格、情緒與關係 — 0.2

這是 RPG OS v1.01 Freeform 的資料與流程落實，沒有新增通用好感點數、說服公式、戀愛等級或必勝話術。原始規則見 `rules/rpg_os_v1_01/OS_AGENT_STATE.md` 的 Personal anchors、Nature and control、Initial Encounter Baseline、Portray and change，以及 `ENGINE_freeform.md` 的 Social requests。模型每次相關裁定會取回已核對的適用原文。

## 人物如何作出反應

人物有持續的個人牽掛和處境；可按需要補充文字性格。例如「容易被真誠的體貼感動，但害怕答應做不到的事」，會使同一個人同時感激又猶豫。這不等於所有請求都成功，也不等於守衛永遠不能離崗。

裁定的問題應是：這個人在這次情境中如何理解對方，現在有甚麼感受、想得到或保護甚麼、有哪些可行選擇？職責、關係與感情可以衝突。已定的物理限制仍成立，工作上的顧慮則須放回具體取捨中判斷。可以接受、拒絕、尋找代班、議價、延後，或主動提出別的安排；沒有固定答案。

在已建立的地理通路上，接受的裁定可以用 `npc_move` 讓人物自行選擇移動。程式不會因為人物職業是守衛就固定禁止他離開；裁定仍須說明其個人原因與實際後果。NPC 移動不會把玩家一起帶走，不會瞬移到未建立的地方，也不會清除對玩家的既有感情。

## 保存的層次

| 層次 | 保存內容 | 改變方式 |
| --- | --- | --- |
| 個人基礎與性格 | 牽掛、慣常反應、界線、容易被甚麼理由打動 | 有依據地建立；深層改變需引用先前已接受的經歷，不每回合重寫 |
| 當下情緒 | 感激、開心、失望、擔心、嫉妒等，可矛盾共存 | 具體經歷及個人解讀；每個感受連到造成它的記憶 |
| 對特定人的長期關係 | 信任、喜愛、尊重、怨懟、恐懼、外貌欣賞、身體吸引、浪漫感情、承諾與界線 | 只更新受到影響的面向；其餘沿用，不把一個面向自動換算成另一個 |
| 重要記憶 | 本人感知到甚麼、如何理解、當時感受、造成哪些變化 | 接受裁定後保存；解讀是人物觀點，不必等於世界真相 |
| 當前參與狀態 | 原本五項 encounter 基礎 | 沿用並按事件更新；與長期關係分開，吸引變動時保留初始依據及指向當前關係的引用 |

未建立的關係是未知，並非零分或沒有感情。數字不是此規則的心理量尺。人物對 A 和 B 的感覺分開保存，A 喜歡 B 不會自動得到 B 喜歡 A。

## 愛情如何可能發展

關心、信任、身體吸引、浪漫感情與承諾可能互相影響，但不是固定階梯。可以先有吸引再建立信任；可以越來越珍惜相處而發現愛慕，也可以只有友情、矛盾、疏遠或完全不相容。沒有「做滿幾件好事一定戀愛」或「必須慢慢累積固定回合」的規則。

例如米拉重視被平等對待。班細心聽她談手藝、尊重她的安排，可能讓她覺得被理解，從而更享受相處；是否發展成浪漫感情，仍需依她自己的性格、當下關係、吸引適用性和後續經歷判斷。另一些人對班沒有相容的浪漫吸引，可能真誠感激或成為朋友，也不會因此愛上他。

已明確建立的吸引不相容，可用 `limits` 約束相應的 `romantic_interest` 或 `sexual_attraction` 面向。不能因追求或送禮自動移除。不把「在工作」「已婚」「很忙」誤當作沒有情感或吸引能力；那些是具體責任和承諾，另作取捨。既有不相容限制的真正修正目前需用明確場外修復，不能靠人格漂移偷偷改掉。

愛情本身不決定每次行為：有感情的人仍可能生氣、拒絕某個要求、擔心失去工作，或主動照顧對方。NPC 的主動性從自身關切而來，沒有每回合一定邀約或製造戲劇的配額。玩家的感受、回應與自願行動仍由玩家決定。

## 程式目前能保證甚麼

- 情緒、關係和記憶只有在裁定接受後才提交，與其他世界事件使用同一個交易、版本與回溯流程。
- 舊提案不能覆寫更新後的關係；`before` 必須與已接受的當前值一致。
- 數字好感值、未知人物、虛構記憶 ID、別人的私密記憶、此版無傳訊來源的不在場感知會被拒絕。
- 人格必須在依賴它的反應之前建立；已建立人格不能每回合重抽。深層改變需引用先前已接受的本人經歷，保留改變前資料。
- 情緒改變不會自動增加浪漫感情或承諾，人物間的關係有方向性。
- 私人感受不出現在普通玩家狀態。主持人可以主動展開私人筆記查看原因；故事只應描寫可感知的行為與對話。
- 舊存檔原有 NPC 和歷史不會在升級或讀檔時被重新生成人格。新欄位按接受的新事件建立。

**程式仍不能證明每段自然語言解讀都心理合理。** 模型可能把一句話理解錯、忽略性格或寫出不受支持的內心變化；因此情緒提案仍需語意審閱。程式檢查來源和資料一致性，不冒稱已建立能完全判斷人心的公式。

## 模型記憶與規則

全部已接受記憶保存在資料庫。每次提示只取相關在場人物、當前關係和部分重要記憶；取回偏向目前情緒／關係的原因及與本次宣告相關的經歷。未取回不等於刪除；需要的前因不在提示時應釐清，不能補造歷史。這是有範圍的檢索，不是完整人格模擬或無限 context。

新的 `等待／共同度過一段時間` 行動提供人物自然主動交談或行動的機會；它不會自動加好感、擲骰、安排事件或偷偷越過玩家未決選擇。遠距通信與完整離場自主世界模擬尚未實作。

單人互動先收窄至該人物的完整個人資料，其他在場者只提供可見概況。裁定步驟先產生可驗證事件，再由人物表達步驟依已定人格、情緒、關係及候選結果寫出直接台詞；不能藉台詞步驟偷加狀態事件。需要其他人物獨立參與時，先取回其個人基礎再分開裁定。這是檢索與表達範圍的限制，不代表世界裡其餘人物停止活動。

目前仍以同一個 Stheno 分別擔任兩個角色；尚未安裝另一個更強的裁判模型。兩步生成增加等待時間，文筆與心理合理性也仍受模型能力限制。測試通過代表資料與權限邊界成立，不代表 NPC 心理已被程式證明。
